# インストール手順（Mac / Chrome）

所要時間は5分ほどです。Chrome が入っていれば、ほかに何もインストールする必要はありません。

## 1. ファイルを置く

1. 受け取った `local-autofill-0.1.0.zip` をダブルクリックして展開します。
2. できたフォルダを、消さない場所に移動します（例：「書類」フォルダ）。
   - **このフォルダを削除すると拡張機能が動かなくなります。**ダウンロードフォルダに置いたままにしないでください。

## 2. Chrome に読み込む

1. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
2. 右上の **「デベロッパー モード」** をオンにします。
3. 左上に出てくる **「パッケージ化されていない拡張機能を読み込む」** を押します。
4. 手順1で移動したフォルダ（`manifest.json` が入っているフォルダ）を選んで「選択」を押します。
5. 「ローカル入力」が一覧に追加され、プロフィール登録の画面が自動で開きます。

## 3. プロフィールを登録する

1. 名前・ふりがな（ひらがな）・生年月日・連絡先・住所を入力して **「保存」** を押します。
2. 仕事用など別の情報を使い分けたいときは「＋ 新しいプロフィール」で追加できます。

## 4. ツールバーに固定する（おすすめ）

1. Chrome 右上のパズルのアイコン 🧩 を押します。
2. 「ローカル入力」の横のピンのアイコンを押すと、ツールバーに常に表示されます。

## 使い方

1. 入力したいフォームのページを開きます。
2. ツールバーの「ローカル入力」アイコンを押して **「このページに入力」**。
   - キーボードなら **Option + Shift + F** でも入力できます。
3. 入力された内容を確認してから、ご自身で送信してください。

うまく入らない欄があったら：

- ポップアップの **「欄の割り当てを確認」** を押し、違っている欄の項目を選び直して **「このサイト用に保存して入力し直す」**。次回からそのサイトでは正しく入ります。
- 間違って入力したら **「入力を元に戻す」**。

## よくある質問

**Q. 情報が外部に送られることはありますか？**
ありません。登録した情報はこのMacの Chrome の中にだけ保存され、ネットワークには送信しません。

**Q. Chrome を起動するたびに「デベロッパーモードの拡張機能を無効にする」と出ます。**
ストア経由でない拡張機能を読み込んだときに表示されるお知らせです。「×」で閉じればそのまま使えます（「無効にする」は押さないでください）。

**Q. 新しいバージョンをもらったら？**
古いフォルダの中身を新しい zip の中身に入れ替えて、`chrome://extensions` で「ローカル入力」の 🔄（更新）ボタンを押してください。登録したプロフィールはそのまま残ります。

**Q. 別のパソコンに移したい／バックアップしたい**
プロフィール画面の「ファイルに書き出す」で保存し、移行先で「ファイルから読み込む」を使います。書き出したファイルには個人情報が含まれるので、取り扱いに注意してください。

**Q. ショートカットを変えたい**
`chrome://extensions/shortcuts` で変更できます。
