# インストールと使い方（Mac / Chrome）

所要時間は5分ほどです。Chrome が入っていれば、ほかに何もインストールする必要はありません。
名簿のデータはこの Mac の Chrome の中だけに保存され、外部には送信されません。

## 1. ファイルを置く

1. 受け取った `local-autofill-0.4.0.zip` をダブルクリックして展開します。
2. できたフォルダを、消さない場所に移動します（例：「書類」フォルダ）。
   - **このフォルダを削除すると拡張機能が動かなくなります。**ダウンロードフォルダに置いたままにしないでください。
   - **読み込んだ後は、フォルダの場所を変えないでください。**別の場所に移して読み込み直すと Chrome からは別の拡張機能として扱われ、名簿が空に見えます（元の場所に戻すと見えます）。移したいときは、先に名簿画面の「バックアップを書き出す」で保存してから移し、移した先で「バックアップから復元」してください。

## 2. Chrome に読み込む

1. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
2. 右上の **「デベロッパー モード」** をオンにします。
   - 会社から支給された Mac などで、このスイッチが無い・押せない場合は、管理者の設定で禁止されています。その Mac では使えません。
3. 左上に出てくる **「パッケージ化されていない拡張機能を読み込む」** を押します。
4. 手順1で移動したフォルダ（`manifest.json` が入っているフォルダ）を選んで「選択」を押します。
5. 「ローカル入力」が一覧に追加され、名簿の画面が自動で開きます。
6. Chrome 右上のパズルのアイコン 🧩 →「ローカル入力」のピンを押して、ツールバーに固定しておくと便利です。

## 3. 名簿を用意して取り込む

1. 名簿画面の **「ひな形CSVをダウンロード」** で見本を保存し、Numbers か Excel で開きます。
2. 1行目は見出し、2行目から1人1行で入力します（見本の行は消してください）。
   - **見出しは変えても足してもかまいません。**「氏名」「フリガナ」「住所」「携帯電話」などは自動で名前・住所・電話として扱います。
   - それ以外の見出し（例：「ご職業」「会員番号」）も **「名簿の列」** として保存します。フォームに同じ名前の欄があれば自動で入力し、名前が違う欄は「欄の割り当てを確認」でその列を選ぶと、サイトごとに覚えます（下の「フォームの欄とCSVの列を対応させる」）。
   - 「氏名」「ふりがな」は姓と名の間にスペースを入れてください。
3. CSV で保存します。
   - Numbers：「ファイル」→「書き出す」→「CSV…」
   - Excel：「ファイル」→「名前を付けて保存」→ 形式「CSV UTF-8」
4. 名簿画面の **「CSVを取り込む」** でそのファイルを選びます。
5. 取り込み後に **「要確認」** が出たら、その人の行を押して直します（姓と名の間にスペースがない、生年月日が読めない、住所を分けられない、など）。
   - 同じ人（氏名＋電話番号などが同じ）がすでに名簿にいる場合は、二重に取り込みません。
6. 一覧で内容を確認します。行を押すと1人ずつ直せます。
   - 「住所」を1列で入れた場合は自動で分けています。市区町村と番地の境目が違っていたら直してください。

> CSV ファイルは個人情報なので、取り込んだ後は不要なら削除するか、安全な場所に保管してください。

## 4. フォームに入力する

1. 入力したいフォームのページを開き、ツールバーの「ローカル入力」アイコンを押します。
2. 名前・ふりがな・電話番号で検索して、入力する人を選びます（Enter で先頭の人を選択）。
3. **「この人をページに入力」**（キーボードなら **Option + Shift + F**）。
4. 入力内容を確認して、ご自身で送信します。
5. 送信できたら **「入力済みにして次の人へ」**。次の未入力の人が自動で選ばれます。

入力後の表示も確認してください：

- **「最初から入力されていたため、そのままにした欄」** … 手で入れた値などを残した欄です。違う人の情報が残っているときは「入力済みの欄も上書きする」にチェックして入力し直してください。
- **「選択肢が合わず選べなかった欄」** … 生まれ年が和暦だけの選択肢になっている場合などです。手で選んでください。
- 前に入力した人の情報が残っていた欄は、自動で書き換えます（「前の人の情報が残っていた○欄は書き換えました」と表示）。

### フォームの欄とCSVの列を対応させる

- フォームの欄名と CSV の見出しが同じ（例：どちらも「ご職業」）なら、何もしなくても入力されます。「ご職業（必須）」のような書き方の違いは気にしなくて大丈夫です。
- 名前が違う欄（例：フォームは「お客様番号」、CSV は「会員番号」）は、ポップアップの **「欄の割り当てを確認」** でその欄の選択肢から **列「会員番号」** を選び、「このサイト用に保存して入力し直す」を押します。次からそのサイトでは自動で入ります。
- 名前や住所などの欄も、同じ方法で好きな項目・列に変えられます。

うまく入らない欄があったら：

- **「欄の割り当てを確認」** で、違っている欄の項目を選び直して **「このサイト用に保存して入力し直す」**。次回からそのサイトでは正しく入ります。
- 間違って入力したら **「入力を元に戻す」**。

## 5. 練習してみる（任意）

配布セットの「練習用」フォルダに、練習用のフォームと架空の名簿が入っています。実際のサイトで使う前に動きを確かめられます。

1. `chrome://extensions` の「ローカル入力」で **「詳細」** を開き、**「ファイルの URL へのアクセスを許可する」** をオンにします（パソコンの中のファイルを開いたページで使うために必要です。実際のサイトでは不要です）。
2. 名簿画面で「取り込む前に今の名簿を全部消す」にチェックを入れずに、`練習用名簿.csv` を取り込みます（すでに本番の名簿がある場合は、先に「バックアップを書き出す」で保存しておくと安心です）。
3. `練習用フォーム.html` を Chrome の画面にドラッグして開き、ツールバーの「ローカル入力」から入力してみます。
   - 「ご職業」は名簿の列と同じ名前なので自動で入ります。
   - 「お客様番号」は名前が違うので、「欄の割り当てを確認」で列「会員番号」を選ぶ練習ができます。
4. 終わったら、名簿画面で練習の3人（練習 太郎・見本 花子・試験 次郎）を削除するか、本番の名簿を「取り込む前に今の名簿を全部消す」にチェックを入れて取り込み直します。

## 6. 進み具合の確認・書き出し

- 名簿画面の上に「入力済み ○人・未入力 ○人」が出ます。「未入力のみ」で絞り込めます。
- **「CSVに書き出す」** で、入力済みの日時つきの名簿を保存できます（Excel でも文字化けしません）。

## よくある質問

**Q. 情報が外部に送られることはありますか？**
拡張機能からは送りません（通信できないように設定してあります）。ただし、入力した先のサイトが送信前に住所の自動補完などで通信することはあります。これは手で入力したときと同じです。

**Q. Chrome を起動するたびに「デベロッパーモードの拡張機能を無効にする」と出ます。**
ストア経由でない拡張機能を読み込んだときのお知らせです。「×」で閉じればそのまま使えます（「無効にする」は押さないでください）。

**Q. 新しいバージョンをもらったら？**
古いフォルダの中身を新しい zip の中身に入れ替えて、`chrome://extensions` で「ローカル入力」の 🔄（更新）ボタンを押してください。名簿はそのまま残ります。

**Q. バックアップは？**
拡張機能を削除すると名簿も消えます。名簿画面の「バックアップを書き出す」でときどき保存してください（サイトごとの割り当ても含まれます）。

**Q. Mac 自体のセキュリティは？**
名簿は他の人の個人情報なので、「システム設定」→「プライバシーとセキュリティ」→ **FileVault** をオンにしておくことをおすすめします。
