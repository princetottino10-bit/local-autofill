使い方は3ステップ

最初に名簿を取り込めば、あとはフォームを開くたびに人を選んで押すだけです。

  1. 名簿を取り込む

    Numbers や Excel で作った名簿をCSVで保存して取り込みます。「氏名」「フリガナ」「住所」が1列ずつでも自動で分け、読めなかった値は取り込み時に知らせます。

  2. 人を選んで入力

    ツールバーのボタンから名前・ふりがな・電話番号で検索して選び、「この人をページに入力」。ショートカット ⌥⇧F でも入力できます。

  3. 確認して、次の人へ

    内容を確かめて自分で送信。「入力済みにして次の人へ」で次の未入力の人に進みます。進み具合は名簿画面で一覧できます。

名簿はパソコンの外に出ません

扱うのは他の人の個人情報なので、仕組みごと外に出さない作りにしています。

  • 保存先はChromeの中だけ名簿は拡張機能の中に保存されます。クラウドやAIのサービスには送りません。
  • 通信そのものを禁止拡張機能のページはネットワークにつながらない設定にしてあり、仮にコードを書き換えてもChromeが止めます。
  • 押したタブにだけ作用ボタンを押したページ以外には触れません。ほかのサイトを読み取る権限も持っていません。
  • 見えない欄には入れない透明な欄や画面の外に隠した欄には入力しません。名前だけ聞くふりをして住所や電話番号を抜き取るページへの対策です。
  • 送信は自分で送信ボタンは押しません。入力内容を確認してから、ご自身で送信してください。

日本のフォームに合わせた入力

欄のラベルや並び方から、何を入れる欄かを判定します。名簿の形式とフォームの形式が違っても、欄に合わせて変換します。

姓と名が別の欄山田 太郎 → [山田] [太郎]
郵便番号の分割150-0001 → 〒[150]-[0001]
ひらがな・カタカナやまだ → フリガナ欄にはヤマダ
和暦の生年月日平成2年4月1日 → 1990年4月1日
電話番号の3分割09012345678 → [090]-[1234]-[5678]
「全角で」の指定1-2-3 → １－２－３
住所のまとめ・分け都道府県＋市区町村＋番地 → 1つの欄にも
関係ない欄は空けておく件名・物件名・お問い合わせ内容
前の人の情報は書き換え鈴木 花子 → 高橋 一郎（手入力の値は残す）
初期値も直す都道府県が最初から「東京都」→ 北海道
入力するフォームを選ぶログイン欄・メルマガ欄には入れない
間違えた欄は覚え直すサイトごとに割り当てを保存

苦手なこと

入らない欄があっても、ポップアップの「欄の割り当てを確認」で直せる場合があります。

  • 別サービスの埋め込みフォームHubSpot・formrun などの埋め込みや、カード決済欄
  • 見た目だけの独自プルダウン普通の選択欄でないものは選べません
  • 複数ページに分かれたフォームページごとにボタンを押せば入ります
  • 名簿にない項目ローマ字の名前、半角カナ、年齢、職業など
  • 画像認証（CAPTCHA）人が操作する前提のものには触れません
  • クレジットカード・パスワード安全のため、あえて対象外にしています

ローカル入力 …

 

中身：拡張機能のフォルダ（local-autofill-extension）・手順書（はじめにお読みください.html）・名簿のひな形CSV

はじめて使うとき

  1. ダウンロードした zip をダブルクリックして展開し、できたフォルダを「書類」など消さない場所に置きます。
  2. Chrome で chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。
  3. 「パッケージ化されていない拡張機能を読み込む」で、フォルダの中の local-autofill-extension を選びます。
  4. 開いた名簿画面で名簿のCSVを取り込みます（ひな形CSVも同じフォルダに入っています）。

新しい版に更新するとき

  1. このページから最新版をダウンロードして展開します。
  2. いま使っている local-autofill-extension フォルダの中身を、新しいものの中身に入れ替えます。フォルダ自体の場所や名前は変えません。
  3. chrome://extensions の「ローカル入力」にある 🔄（更新）ボタンを押します。名簿はそのまま残ります。

いま使っている版は、chrome://extensions の「ローカル入力」の欄に表示されています。

必要なもの Chrome が入ったパソコン（Mac / Windows）。ほかに何もインストールしません。 名簿は他の人の個人情報です。Mac では FileVault（ディスクの暗号化）をオンにしておくと安心です。 このページから受け取るのは拡張機能だけです。名簿のデータがこのページを通ることはありません。
